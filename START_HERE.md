# Cairn: подготовка к переработке интерфейса

Это личный форк [arttvad9r/cairn](https://github.com/arttvad9r/cairn) из
[Ratpido-dev/cairn](https://github.com/Ratpido-dev/cairn).

**Сейчас:** русский перевод перенесён в исходники; подготовлены план и среда разработки.
Переработка интерфейса ещё не началась. Установленная рабочая версия трекера не заменялась.

**Цель:** переработать оба интерфейса — игровые панели и окно запуска/настроек.
Сохранить корректное отслеживание партий, русский язык и работу в KDE Wayland.
Конкретные макеты и визуальный стиль пока не утверждены.

## С чего начать следующий сеанс

1. Открыть эту папку как проект в Codex.
2. Прочитать [AGENTS.md](AGENTS.md) и [состояние проекта](docs/redesign/STATE.md).
3. Выполнить аудит сценариев из [плана](docs/redesign/PLAN.md), затем подготовить
   макеты обеих частей интерфейса. Существенные решения о поведении обсудить до реализации.
4. После выбора макета переносить его небольшими проверяемыми этапами.

Пример задачи для следующего чата:

> Продолжаем Cairn. Прочитай START_HERE.md и документы docs/redesign.
> Начни с аудита текущего интерфейса и предложи макеты игровых панелей и окна настроек.
> Пока не меняй установленный трекер и не реализуй неподтверждённое поведение.

## Разработка отдельно от рабочей установки

```bash
./scripts/dev-setup.sh
./scripts/test.sh
./scripts/dev-run.sh
```

`dev-setup.sh` создаёт `.venv`, устанавливает проект и pytest, загружает четыре локали
карт в игнорируемую папку `data/cards`. Нужны Python ≥ 3.10, venv и доступ к сети.
`dev-run.sh` использует настройки/историю/кэш в `.dev`, а не рабочие пользовательские файлы.
В разработческой конфигурации отключена отправка партий. Не запускайте рабочий и
разработческий трекер одновременно: у приложения единый механизм экземпляра.

Если префикс игры не определился, укажите его в интерфейсе разработки либо при первом запуске:

```bash
CAIRN_DEV_HS_PREFIX=/path/to/prefix ./scripts/dev-run.sh
```

Скрипт запускает только Cairn. Он не запускает игру, не меняет правила KDE и не устанавливает
приложение в `~/.local`. Кнопки настройки журналов и запуска игры внутри Cairn по-прежнему
могут выполнять соответствующие действия — изолирована среда трекера, не сама игра.
